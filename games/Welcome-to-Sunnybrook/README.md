## 安装说明

1. 完全退出游戏。旧汉化用户先用Steam验证完整性，恢复Build 26263825匹配原版，再备份重要文件；不要在旧包上强行安装。
2. 游戏所在磁盘建议预留至少 **7 GiB**，用于备份、生成文件和失败回滚。
3. 将 ZIP **全部内容**解压到包含 `Sunnybrook.exe` 和 `Sunnybrook_Data` 的游戏根目录，保留内部结构，不要额外套一层文件夹。
4. 双击 `Install_CN.cmd`，等待 `Success: Install`。原版、工具或差分校验不符会停止；全部新文件生成并核对后才替换游戏文件。
5. 原版备份位于游戏目录的 `Sunnybrook_ChinesePatch/Backup`，请勿删除。正常启动游戏即可，无需选择新增语言，也不需要联网、Python、额外字体或汉化插件。

安装期间不要启动、更新游戏或强行中断进程。系统通常自带的 Windows PowerShell 即可执行；游戏目录须有写入权限。安装器不会自行启动游戏。

完全相同的汉化重复安装不会改写游戏文件。如果之前安装的是本地直接覆盖版，且没有本安装器的原版备份，无法直接凭空还原；请先使用 Steam 验证完整性恢复。

## 卸载说明

退出游戏，双击 `Restore_Original.cmd`，从通过哈希校验的备份恢复原版。还原后保留备份。没有备份、游戏已更新或文件不匹配时，使用 Steam 验证游戏文件完整性。

确认恢复原版后，可自行移除安装入口和 `Sunnybrook_ChinesePatch` 文件夹；该文件夹包含备份，未确认恢复前不要删除。不要删除整个 `Sunnybrook_Data` 或存档。
