## 安装说明

```text
《デテイケ -GetOut-》简体中文覆盖补丁

汉化署名：5050汉化组：Cokepoetry汉化
适用版本：Steam Windows 版，Unreal Engine 5.3，64 位，IoStore 资源格式

【安装】
1. 完全退出游戏。
2. 将本压缩包内的全部内容复制到：
   E:\SteamLibrary\steamapps\common\デテイケ -GetOut-
3. 选择合并文件夹；本补丁只新增汉化容器，不覆盖游戏原始 PAK、UTOC 或 UCAS。
4. 从 Steam 正常启动游戏，保持游戏原生显示设置。

【卸载】
删除以下四个新增文件即可恢复原版：
GetOut\JuonV003\Content\Paks\JuonV003_Chinese_P.pak
GetOut\JuonV003\Content\Paks\JuonV003_Chinese_P.utoc
GetOut\JuonV003\Content\Paks\JuonV003_Chinese_P.ucas
GetOut\JuonV003\Content\Paks\JuonV003_Chinese_Font_P.pak

【说明】
- 补丁完全离线运行，不需要安装 Unreal Editor、BepInEx 或其他汉化工具。
- 补丁包含程序文本、蓝图硬编码文本、UEXP DataTable 字幕/聊天文本以及中文字体回退。
- 不修改存档、窗口模式、分辨率、帧率、输入、音频或游戏流程。
- 安装前若已存在同名汉化文件，请先自行保留备份；制作过程中同步到游戏目录时也会自动备份同名旧文件。
- 本次仅做静态解析、构建、回读和哈希校验，没有启动游戏。实际字体、排版、水印、场景流程和遗漏情况请由用户手动验证。

【建议手动检查】
1. 主菜单中“开始游戏”及其下方的汉化署名是否正常显示。
2. 开场回家后的 9 条字幕、Biscard 聊天、对白、物品、交互提示和设置页是否完整。
3. 中文是否出现方框、缺字、重叠或越界。
4. 墙面、纸张、屏幕和设备上的关键视觉文字是否影响理解或解谜。
```
