## 安装说明

```text
UNBEATABLE 简体中文覆盖包

适用对象：Windows Steam 英文原版，Unity Mono x64。
汉化方式：BepInEx 5.4.23.5 运行时汉化，不修改游戏原始资源。

安装：
1. 完全退出游戏。
2. 打开 Steam 游戏目录（能看到 UNBEATABLE.exe 的文件夹）。
3. 将本覆盖包内的全部文件和文件夹复制进去，选择合并/覆盖。
4. 从 Steam 正常启动游戏。

正确目录示例：
E:\SteamLibrary\steamapps\common\UNBEATABLE\

汉化核心文件：
BepInEx\plugins\UNBEATABLEChinese\UNBEATABLEChinese.dll
BepInEx\plugins\UNBEATABLEChinese\translations.csv

请勿只复制到 UNBEATABLE_Data 文件夹；BepInEx 必须位于 UNBEATABLE.exe 同级目录。

卸载：
1. 完全退出游戏。
2. 删除游戏根目录的 winhttp.dll、doorstop_config.ini、.doorstop_version。
3. 删除 BepInEx\plugins\UNBEATABLEChinese 文件夹。
4. 若游戏中没有其他 BepInEx 插件，也可删除整个 BepInEx 文件夹。

兼容说明：
- Steam 验证游戏文件或游戏大版本更新后，可能需要重新安装本覆盖包。
- 缺少翻译时插件会保留英文原文，不会清空文字或阻断对话。
- 本版修复了角色姓名被错误对白替换的问题，并补充了结构化物品说明、成就、章节与硬编码文字。
- 按照用户要求，制作过程中没有启动游戏；实际显示、字体、布局与流程由用户手动验证。
```
