## 安装与升级

1. 完全退出游戏，解压整个ZIP。将**游戏根目录文件夹**拖到 **`安装汉化.cmd`** 上；根目录包含 `Aspis.exe` 和 `Aspis` 子文件夹。
2. 也可把包内所有文件和 `payload` 一起放到游戏根目录，再双击 `安装汉化.cmd`。不要只复制PAK或单独运行 `Repair-ASPIS.ps1`。
3. 安装器校验原版EXE、原始PAK/UTOC和补丁，再备份、生成文字修订并部署自有补丁文件。版本、哈希或备份不匹配时停止，不要绕过校验。
4. 支持已核验原版、此前本地v0.1及已发布v0.2。保留原版EXE备份；v0.2中文PAK升级时也保留旧文件备份。未知文件不会强行覆盖。
5. 成功后自行启动游戏，使用原有中文语言环境。本包不修改语言、画质、输入、帧率或存档设置，也不会启动游戏。

备份文件仅供本机还原，请勿删除或分享。安装器无需Python、外置字体或运行时注入工具。

## 还原与兼容性

退出游戏，将同一游戏根目录拖到 `Restore.cmd`。它使用已核验原版备份恢复主程序，仅移除固定路径且哈希匹配的自有中文PAK及 `ASPIS_Chinese_NativeText_P` 三件套，不删除其他PAK或存档。原版和历史覆盖文件备份保留。

若缺少原版备份，已是目标版本的安装可能仅警告，但还原仍需正确备份；建议始终保留。游戏更新或其他补丁修改文件后可能拒绝安装。Steam验证完整性可恢复原版，但不一定清除新增补丁文件。

主程序修复改的是中文缺分支时使用的俄文回退值，因此俄语模式的相同界面也可能显示中文。安装和还原跨多个文件；失败时可能部分完成，必须保留备份并阅读错误提示。
