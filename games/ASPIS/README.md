## 修订内容

基于当前游戏资源内已有的简体中文语言表进行补漏和润色，不把原有译文冒充全部重新翻译。Steam 商店当前语言列表未列简体中文，因此不据此宣称游戏已正式提供官方中文支持。

- 3,877条语言表记录完成首轮审读，应用其中 **300条**已复核修订，包括生硬表达、误译、专名及设备名称不一致。
- 修复 **117处**主程序内置文案，涵盖存档、章节、设置、底部操作提示和终端状态；其中36处已包含在本地 v0.1，新增81处。
- 包含29条设备及解谜操作提示，涉及光谱分离器、合成器、桥式起重机等；保留通道 **А／Б**、比例参数、数值、操作绑定与解谜逻辑。
- 随包提供《全文修改对照.txt》和《上下文待核清单.txt》供审核。

**这不是完整精翻或零遗漏版本。**仍有1,281条记录未满足完整上下文QA要求，保留原译；不表示这些条目全部存在错误。尚未完成全量图片、无本地化键文本的闭环核查，游戏内字体与布局仍待手动验证。

## 安装说明

1. 完全退出游戏，保留已有原版备份；从发布页下载ZIP，解压到任意独立文件夹。
2. 打开解压后的 `ASPIS_简体中文文字优化` 文件夹。将**游戏根目录文件夹**拖到 **`安装汉化.cmd`** 上；游戏根目录是包含 `Aspis.exe` 和 `Aspis` 子文件夹的目录。
3. 也可将包内全部安装文件和 `payload` 放到游戏根目录，再双击 `安装汉化.cmd`。不要只复制PAK，也不要单独运行 `Repair-ASPIS.ps1`。
4. 入口会核对主程序、原始PAK/UTOC基线、补丁及必要的备份；校验成功后生成修订主程序并部署中文PAK。遇到版本或哈希不符应停止，不要跳过校验。
5. 安装成功后手动启动游戏，保持中文语言环境。本包不修改语言、画质、输入、帧率或存档设置，不会启动游戏。

**包内说明中的 `Install.cmd` 是旧入口名称，实际文件已命名为 `安装汉化.cmd`，请以这里的实际文件名为准。**`Restore.cmd` 名称未变。

安装器会在本机保存原版主程序备份，文件名以 `.ASPIS_CN_8f3ad8c50e34.bak` 结尾。请勿删除或分享此备份。安装器脚本是必要补丁组件，不需要Python、运行时注入插件或额外字体。

## 还原与兼容性

退出游戏，将同一游戏根目录拖到 `Restore.cmd`。安装器只移除哈希匹配的自有 `ASPIS_Chinese_Review_P.pak`，并使用已核验的本机备份恢复原版主程序；不会删除其他PAK或玩家存档。

支持匹配校验值的未修改原版及清单列出的本地 v0.1；从 v0.1 升级必须保留正确的原版备份。旧 v0.1 本次不另行发布，当前ASPIS只有此独立Release。

游戏更新或主程序被其他补丁修改后，安装器可能拒绝处理；这时不要强行覆盖。缺少备份时可通过Steam验证完整性恢复原版主程序，但验证完整性不一定会移除新增PAK，应另行按还原说明处理。

主程序文字修改作用于中文模式回退使用的俄文默认文案，因此**俄语模式及使用相同回退文案的其他场景也可能显示中文**。这不是按当前语言动态切换的补丁。

安装和还原分为主程序、PAK两个阶段，不是跨文件事务。中途失败会明确提示可能部分完成；保留备份，排除错误后重新执行安装或还原。
