## 安装说明

1. 完全退出游戏，先备份将被覆盖的同名文件。
2. 将 ZIP 中的 `THE WRONG WAY_Data` 文件夹解压到包含游戏主程序的根目录，与原有同名文件夹合并并覆盖。
3. 不要解压成 `THE WRONG WAY_Data/THE WRONG WAY_Data` 双层目录。
4. 使用原英语语言槽位；菜单中该槽位显示为“简体中文”。其他语言不是本补丁的翻译目标。
5. 本次应用户要求只修订并发布覆盖包，没有写入重新下载后的本机游戏目录；需要用户自行安装。

这是直接覆盖版，**33 个修改文件**所在的资源容器内仍包含未改动的数据，因此体积较大；不包含可独立运行的完整游戏。
