## 汉化内容

新版原语言表有3,107条记录，构建后含5,738个查表键；迁移程序内578处字串及27处仅文字显示出口，覆盖已定位的菜单、调查委托、商店、调查指南、教程、照片标签与提示。额外语言表键主要服务动态组合标签，不能当作同等数量的独立对白。

不改变存档、输入、联网协议、帧率、分辨率或玩法逻辑。补丁不能独立运行。

## 安装说明

1. 完全退出游戏。已装旧包时，先在Steam验证游戏文件完整性，恢复Build 26270415原版，再备份即将覆盖的同名文件。
2. 将 ZIP 中的 `SEVERANCE_Data` 文件夹复制到包含游戏主程序的根目录，合并文件夹并替换同名文件。
3. 不要解压成 `SEVERANCE_Data/SEVERANCE_Data` 双层目录。
4. 补丁替换原英语语言槽位；该槽位的菜单名称显示为“简体中文”。若仍选着其他语言，请切换到此槽位；不需要安装插件。
5. 首次进入先检查主菜单中文与署名，再查看地图、难度、商店和教程。保持原有显示设置，不必删除存档。

ZIP内说明保留了制作时“本地覆盖版／没有上传GitHub”的描述；用户于2026-10-28随后授权本次公开更新。发布仅更改附件名称，不改动已校验的本地ZIP内容。2026-10-27旧附件已撤下，不要再叠加旧包。
