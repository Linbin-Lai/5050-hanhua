## 安装说明

```text
《Fallen Leaf》简体中文覆盖包

适用版本：Steam Windows 版 1.0.1.18（GameMaker Studio 1.4）

安装：
1. 完全退出游戏。
2. 建议先通过 Steam 验证游戏文件，恢复纯英文原版。
3. 将本 ZIP 第一层的全部文件复制到包含 Fallen Leaf.exe 的游戏根目录。
4. 确认覆盖 data.win。

本版修复：
- 中文字体完整内嵌于 data.win，不依赖外部字体。
- 修复返回标题画面时中文字体被清理，导致“开始游戏 / 设置 / 退出游戏”消失或变黑的问题。
- 标题菜单每次绘制都会恢复正确字体、白色文字和左对齐状态。
- 修复游戏旧式彩色文字编码破坏中文的问题。原资源中的“花瓣”不会再显示成“药”。
- 8 个文字着色函数不再偏移 Unicode 字符；相关局部彩色强调将显示为普通白字，以确保所有中文稳定可读。
- 定点修正暂停菜单、图鉴和收藏品说明中的明显机翻、错义及人物名不一致。
- 署名为“开始游戏”上方的独立小字。
- HUD 金币继续使用原生像素字体，避免与边框重叠。

卸载：
- 在 Steam 中验证游戏文件，恢复原版 data.win。

注意：
- 游戏更新后请勿继续覆盖本包，应等待适配新版本。
- 本包不会修改存档、分辨率、全屏、帧率或输入设置。
- 按照用户要求，本次没有启动游戏、没有进行游戏内截图或运行测试，实际显示与流程由用户手动验证。
```
