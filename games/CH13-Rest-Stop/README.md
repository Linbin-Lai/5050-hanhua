**汉化作者：Cokepoetry**

《CH13: Rest Stop》是 Yellow Smile 开发并发行的心理恐怖游戏，背景为21世纪初的波兰。本补丁将游戏标题译为“休息站”，不是官方中文名称。

## 发布信息

- 补丁版本：v1.0（2026-11-01）。
- 发布状态：发布准备中。
- Steam AppID：`3927170`；适配 Build `26339105`，游戏 `v1.021`。
- 引擎：Unity `6000.0.73f1`，Windows x64 / Mono。
- 补丁形式：Unity 静态资源及原程序集显示文字直接覆盖，无注入插件。
- 文件：`CH13_Rest_Stop_简体中文覆盖包.zip`。
- 大小：`95,645,451` 字节（约95.65 MB / 91.21 MiB）。
- 压缩包：28个文件，包含24个修改后的游戏文件和4个说明、许可及校验文件。
- SHA-256：`6e1f7383e99ebb6544328c97b362d7d5d680b7579c1a519f3051379ccb0098a9`。
- 发布页面：[CH13: Rest Stop 简体中文汉化 v1.0](https://github.com/Linbin-Lai/5050-hanhua/releases/tag/ch13-rest-stop-cn-20261101)。

## 汉化内容

- 447条原生语言表记录、199项设置显示记录、场景文字和14处脚本显示常量。
- 中文静态字体及回退链，主菜单右下角独立署名。
- 手机屏幕、“离开”提示、标题、家庭照片留言及主要警示文字。
- 保持原存档、输入、帧率、分辨率、玩法及联网逻辑不变。

## 安装说明

1. 完全退出游戏，备份将被覆盖的文件。
2. 将 ZIP 中的 `CH13 Rest Stop_Data` 文件夹复制到游戏根目录，与原文件夹合并并替换同名文件。不要放入双重的同名目录。
3. 正常启动游戏，在右上角语言菜单选择“简体中文”。本补丁替换原 **English** 槽位，内部代码仍为 `en`；其他语言不属于本次汉化范围。
4. 不需要安装第三方插件或系统字体，保持游戏原生显示设置。

典型目录：`SteamLibrary\steamapps\common\CH13 Rest Stop`。

## 卸载说明

用安装前备份还原对应文件，或在 Steam 中验证游戏文件完整性。不要直接删除整个游戏数据目录，也不要在游戏运行时覆盖或还原。

## 兼容性与保留项

- 仅适配上述 Build，可在对应的未汉化原版直接安装；游戏更新后旧补丁可能造成显示或启动异常，请等待重新适配。
- 地图保持原始图像，避免改变路线、地名、蓝色标记或数字：`OBJAZD` 意为“绕行”，`Lublin` 对应“卢布林”。
- 包装品牌、素材作者/网址/许可证、路牌专名 `STRAIGHT ST`、`U.S. MAIL` 及极小装饰细则保留原文；部分旧场景草稿和测试占位不作为正式翻译记数。
- 未额外制作语音或视频字幕，不宣称所有画面文字、低概率流程均已覆盖。
- 初轮解析异常中的553项已通过核对空托管引用尾部恢复；另48个设置组件单独核对有效字段和尾部，语言提供器已修正；其余62项为渲染、灯光或道路组件，不宣称全部完整解析。

- ZIP 完整性、内部层级及24个修改文件的哈希与安装结果一致。
