```text
《Backrooms The Multiverse》简体中文覆盖包
5050汉化组：Cokepoetry汉化

安装方法
1. 完全退出游戏。
2. 将本覆盖包内的 BackroomsMultiverse 文件夹复制到游戏根目录。
3. 选择合并文件夹；出现同名文件时选择覆盖。
4. 从 Steam 正常启动游戏，保持游戏原生全屏设置。

E:\SteamLibrary\steamapps\common\Backrooms The Multiverse
```
