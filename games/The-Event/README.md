## 汉化内容

本补丁提供游戏文本简体中文翻译、中文字体兼容以及主菜单汉化署名。署名固定在主菜单屏幕中下方，不与菜单按钮绑定，进入游戏后自动消失。

## 安装说明

1. 完全退出游戏。
2. 将压缩包内容解压到包含游戏主程序的根目录。
3. 允许合并 `TheEvent` 文件夹并覆盖同名文件。
4. 安装后的补丁路径为 `TheEvent/Content/Paks/TheEvent_Chinese_P.pak`。

## 卸载说明

删除 `TheEvent/Content/Paks/TheEvent_Chinese_P.pak`，然后通过 Steam 验证游戏文件完整性。
