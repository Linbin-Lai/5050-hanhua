## 安装说明

```text
Funnel Runners 简体中文汉化补丁
5050汉化组：Cokepoetry汉化

安装方法
1. 完全退出游戏和 Steam 的游戏进程。
2. 将压缩包中的全部内容复制到 Funnel Runners 游戏根目录。
3. 保持目录结构不变；复制后应存在：
   StormEscape\Content\Paks\StormEscape_Chinese_P.pak
   StormEscape\Content\Paks\StormEscape_Chinese_P.utoc
   StormEscape\Content\Paks\StormEscape_Chinese_P.ucas
4. 从 Steam 或 FunnelRunners.exe 正常启动游戏，使用游戏原生显示设置。

本版内容
- 开场与“观看教程”共用的英文教程视频已内嵌简体中文字幕，保留原英文配音。
- 修正房间难度/时段、飞镖、车辆维修示意图等短词和全大写文字遗漏。
- 加载与着色器编译界面改用无字体特效材质的正文样式，以减少白色底块和文字重叠。
- 已基于 2026-07-19 游戏更新后的资源重新构建，适配新增的语音活动指示器、按键说话说明、F5 距离显示和队友语音设置。

卸载方法
删除以下三个文件即可，不要删除原版 StormEscape-Windows 或 global 文件：
StormEscape\Content\Paks\StormEscape_Chinese_P.pak
StormEscape\Content\Paks\StormEscape_Chinese_P.utoc
StormEscape\Content\Paks\StormEscape_Chinese_P.ucas

兼容说明
- 适用于制作补丁时检测到的 Windows 64 位 Unreal Engine 5.6 Steam 版本。
- 本覆盖包对应 2026-07-19 检测到的游戏资源版本；更早的汉化容器不能继续用于该版本。
- 覆盖包不需要安装 Unreal Editor、BepInEx 或其他汉化工具。
- 游戏更新后若资源版本变化，可能需要重新制作补丁。
- 本补丁不会修改窗口模式、分辨率、帧率、时间缩放、输入设置或存档。
- 按照用户要求，制作过程中没有启动游戏；字体、布局、视觉贴图和流程效果需要用户手动检查。

手动检查建议
1. 检查主菜单“开始游戏”及其下方汉化署名。
2. 检查任务、物品交互、教程、设置、加载提示、多人大厅和剧情文档。
3. 检查中文字体是否出现方框、缺字、重叠或溢出。
4. 检查车辆维修示意图、路牌、出口、警告、白板、报纸和文档贴图。
5. 若发现问题，请提供截图、出现位置、原文和 Saved\Logs 下的日志。
```
