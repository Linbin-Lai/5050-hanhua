## 安装

1. 完全退出游戏，并备份可能被覆盖的文件。
2. 下载 `CULTIC.v1.9.7z`，将压缩包中 `补丁` 文件夹内的全部内容复制到 CULTIC 游戏根目录并覆盖同名文件。
3. 正常启动游戏后选择 `English` 语言。
4. 游戏更新后若汉化失效，可重新覆盖补丁；若版本差异导致异常，请先通过 Steam 验证游戏文件完整性恢复原版。
