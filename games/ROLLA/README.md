## 汉化内容

覆盖包汉化了已定位的菜单、关卡目标、新闻标题、部分操作说明和结算文本，并让相关中文文本组件使用游戏资源中的中文字体。主菜单“开始”下方带有“5050汉化组：Cokepoetry汉化”署名。图片、视频和低频动态文本不保证全部汉化；本补丁不修改游戏规则、存档或排行榜数据。

## 安装说明

1. 完全退出游戏，备份将被覆盖的 `ROLLA_Data` 文件。
2. 将 ZIP 第一层的 `ROLLA_Data` 文件夹解压到含 `ROLLA.exe` 的游戏根目录，允许覆盖同名文件。`使用说明.txt` 和 `翻译对照.csv` 可一同保留作参考。
3. 正常启动游戏；本补丁直接覆盖英文资源，不需要选择额外语言。

若此前安装了其他版本汉化，建议先通过 Steam 验证游戏文件完整性，再安装本版，避免混用资源。
