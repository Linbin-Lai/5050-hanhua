## 汉化与修复

已处理定位到的菜单、剧情、物品、文档、主要解谜图片和重要环境标牌；部分包装、书脊等装饰小字仍保留原文，不宣称全部图片均已汉化。主菜单仅“开始游戏”后附带同字号单行汉化署名，“继续游戏”不附署名。

文档正文增加中文换行并修正自动缩小问题，保留滚动阅读和原有解谜信息。

本版顺便修复了无按键时角色自动移动的输入问题：抑制未回中的异常模拟轴输入，键盘松键后不保留移动方向。没有删除手柄或 XR 绑定；使用手柄时，启动游戏或切回游戏后先松开摇杆回中一次。该修复已通过离线输入测试，修复后的实际游戏效果仍需玩家手动确认。

## 安装

1. 完全退出游戏，备份重要文件；游戏所在磁盘建议预留至少 15 GiB。
2. 旧版汉化用户先用旧包的“还原英文.cmd”恢复原版；没有原版备份时，通过 Steam 验证完整性恢复，不能强制混装。
3. 将 ZIP 全部内容解压到包含 `ALYSSA_Data` 的游戏根目录，保留 `ALYSSA_ChinesePatch` 内部结构。
4. 双击“安装汉化.cmd”。安装器会核对五个原版文件大小和 SHA-256，不匹配则停止，并自动备份到 `ALYSSA_ChinesePatch_Backup_v1`，请勿删除备份。
5. 安装成功后正常启动。本包替换英语栏位，显示名称为“简体中文”，无需新增语言；若原先选择其他语言，请切换到该栏位。

不需要额外 Python、联网或管理员权限，不修改存档、帧率及显示设置。安装期间勿启动或更新游戏。断电、强制结束或文件占用可能妨碍回滚，请保留备份和错误提示中的临时目录。

本版实际包含 **5 份差分**；包内说明后半段保留了上一版“4份”的历史段落，以说明顶部的本版更新及 manifest.json 为准。不要仅复制 .hdiff 文件，也不要把补丁工具当作游戏启动器。

## 卸载与兼容性

退出游戏，双击“还原英文.cmd”恢复安装器备份的五个原版文件；也可通过 Steam 验证完整性恢复。安装器还原后保留备份。游戏更新后可能无法安装或不兼容，不能绕过版本校验。本包不能独立运行，必须配合合法取得的完整原版游戏使用。
