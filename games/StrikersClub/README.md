## 安装说明

```text
Strikers Club 简体中文汉化补丁

汉化署名：5050汉化组：Cokepoetry汉化

安装方法
1. 完全退出游戏。
2. 将覆盖包内全部内容复制到 StrikersClub 游戏根目录。
3. 出现提示时选择合并或覆盖。
4. 从 Steam 或 UFG.exe 正常启动游戏，并保持游戏原生显示设置。

卸载方法
删除以下三个新增文件即可，不要删除 UFG-Windows 原版容器：
UFG\Content\Paks\UFG_Chinese_P.pak
UFG\Content\Paks\UFG_Chinese_P.utoc
UFG\Content\Paks\UFG_Chinese_P.ucas

兼容说明
- 适用于本补丁制作时的 Windows x64 版 Strikers Club。
- 游戏使用 Unreal Engine 5.6 和 IoStore；补丁以新增的高优先级 PAK/UTOC/UCAS 容器加载，不覆盖原版主容器。
- 游戏更新后若资源版本变化、汉化失效或启动异常，请先卸载本补丁并等待适配新版。
- 覆盖包适用于未安装其他汉化工具的纯英文原版，不需要 Unreal Editor，也不依赖联网翻译服务。

手动检查建议
请检查主菜单、署名、中文字体、匹配与自定义比赛界面、教程、技能说明、控制器名称、比分与犯规提示，以及球场广告牌和铲球教程短片。
实际游戏内显示、布局、联网流程和字体回退仍需由用户手动验证。

按照用户要求，制作过程中没有启动游戏、没有进行游戏内截图或运行测试。
```
