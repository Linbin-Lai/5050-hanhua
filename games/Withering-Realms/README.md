## 汉化内容

本补丁提供《Withering Realms》的简体中文 Unity 资源。压缩包包含 `resources.assets`、中文 `sharedassets0` 资源及 `furniture_0_ruinedmansion_assets_all.bundle`。包内没有逐项汉化清单，因此本页不对具体文本、图片或剧情覆盖率作超出静态证据的承诺。

## 安装说明

1. 完全退出游戏。
2. 备份游戏目录中的 `Withering Realms_Data\resources.assets`、`resources.assets.resS` 以及压缩包中其他同名目标文件。
3. 将压缩包中的 `Withering Realms_Data` 文件夹复制到包含游戏主程序的根目录，按目录层级覆盖同名文件。
4. 从 Steam 正常启动游戏并手动检查中文显示。

## 卸载说明

恢复安装前备份的同名资源文件；也可通过 Steam 验证游戏文件完整性恢复官方资源。验证完整性可能同时移除本补丁新增的中文资源。
