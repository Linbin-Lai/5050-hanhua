## 安装

1. 完全退出游戏，备份原有文件。
2. 将压缩包中的 `resources` 文件夹合并覆盖到 Happy Wheels 游戏根目录。
3. 确认安装后的路径为 `Happy Wheels/resources/webroot/...`，不要多套一层文件夹。
4. 重新启动游戏。本包包含现有完整补丁资源，无需叠加旧包。

如果之前安装过实验性帧率版，用本包完整覆盖同名资源可恢复本补丁的原始帧率逻辑。
