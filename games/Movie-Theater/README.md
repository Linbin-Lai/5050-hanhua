## 安装说明

1. 完全退出游戏。
2. 将 ZIP 内全部文件覆盖到包含 `Theater.exe` 的游戏根目录。
3. 确认同名文件已正确合并后，从 Steam 正常启动游戏并保持原生显示设置。

卸载时可通过 Steam 验证游戏文件完整性，或恢复安装前备份的原版文件。

## 汉化内容

- 使用静态 Unity 资源与 `Assembly-CSharp.dll` 精确替换，无需安装 BepInEx。
- 覆盖菜单、剧情、对话、场景硬编码文本和题目图片。
- 中文字体资源随补丁静态嵌入，不依赖用户另行安装字体。
- 使用独立文本对象显示汉化组署名，避免改变主菜单按钮的点击区域和交互逻辑。
- 游戏使用原生字幕系统，本补丁不额外叠加第二套字幕。
