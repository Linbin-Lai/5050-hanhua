# 5050 汉化合集

本仓库用于整理和维护 **5050 汉化组**制作的游戏简体中文补丁、翻译文本、辅助脚本、校验信息及安装说明。

## 项目内容

仓库可能包含：

- 游戏简体中文翻译文本
- 文本导入、导出与静态校验脚本
- 补丁构建说明
- 字体兼容与界面适配记录
- 图片、字幕等本地化项目的处理记录
- 补丁版本、适用游戏版本及文件校验值
- 安装、卸载和问题反馈说明

每款游戏的汉化项目存放在独立目录中，具体完成度、适用版本和已知问题以对应目录内的说明为准。

## 下载与安装

可直接安装的汉化补丁请前往仓库的 **Releases** 页面下载。

安装前请注意：

1. 确认补丁适用于当前游戏版本。
2. 完全退出游戏。
3. 建议先备份补丁将要替换的文件。
4. 按对应游戏目录中的安装说明操作。
5. 游戏更新后，旧版补丁可能失效或导致无法启动。
6. 不要混用不同版本或不同来源的汉化文件。

除非项目说明另有注明，补丁通常需要覆盖到包含游戏主程序的根目录。

## 卸载方法

优先按照对应项目的卸载说明操作。一般可通过以下方式恢复：

- 删除汉化新增的独立补丁文件；
- 恢复安装前备份的原始文件；
- 使用游戏平台的文件完整性验证功能重新下载原版文件。

请勿在没有备份和说明的情况下随意删除游戏资源。

## 完成度说明

本项目会尽可能检查：

- 菜单、设置与系统提示
- 剧情对白和人物名称
- 任务、教程与交互文本
- 字幕及语音对应文本
- 图片、路牌、贴花和模型表面文字
- 字体字形、换行、重叠和可读性
- 变量、控制标签及资源结构

受游戏更新、动态文本、低概率事件、字体渲染和资源封装方式影响，汉化仍可能存在遗漏或兼容问题。

除非有完整且可审计的资源清单，不使用“100% 汉化”描述项目完成度。

## 问题反馈

反馈问题时，请尽量提供：

- 游戏名称及版本号
- 汉化补丁版本
- 问题截图
- 出现问题的位置和操作流程
- 正确原文或能听清的语音内容
- 崩溃提示或日志
- 是否混用了旧补丁或其他模组

请不要只提交“有乱码”“翻译错了”等无法定位问题的信息。

## 仓库结构

```text
5050-hanhua/
├─ README.md
├─ games/
│  ├─ Fallen-Leaf/
│  │  ├─ README.md
│  │  ├─ translations/
│  │  ├─ scripts/
│  │  └─ checksums/
│  └─ 其他游戏/
├─ shared-tools/
└─ docs/
```

- `games/`：各游戏独立汉化项目
- `translations/`：中英文翻译表及术语表
- `scripts/`：文本导入、导出、构建或校验脚本
- `checksums/`：适用版本及补丁文件的校验值
- `shared-tools/`：由本项目编写且可复用的辅助脚本
- `docs/`：通用说明和维护文档
